# Contributing to Research Lab

First off, thank you for considering contributing to the Research Lab project! 

## Getting Started

1. Fork the repository and create your branch from `main`.
2. Follow the setup instructions in `README.md` to run the project locally.
3. Make sure both the frontend and backend are running properly.

## Development Workflow

- Create feature branches with descriptive names: `feature/add-new-question-type` or `fix/button-alignment`.
- Commit messages should be clear and descriptive.

## Code Style

- We use ESLint and TypeScript for the frontend. Please ensure your code passes linting before submitting a PR.
- For the backend, keep the routes, controllers, and services cleanly separated.

## Pull Requests

1. Describe the changes you have made clearly in the PR description.
2. Link any related issues.
3. Request review from the maintainers.

## Issues

If you find a bug or have a feature request, please open an issue with as much detail as possible.
